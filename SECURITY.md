# Security

Do not open public issues for suspected vulnerabilities or package-publishing incidents.

Use [GitHub private vulnerability reporting](https://github.com/Atomics-hub/zod-schema-bridge/security/advisories/new). Include affected versions, a minimal reproduction, impact, and any suggested remediation. We aim to acknowledge reports within three business days.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| < 0.2 | No |

Releases use npm trusted publishing/provenance and a GitHub artifact attestation. Maintainers must enable phishing-resistant two-factor authentication on npm and GitHub before the first public release.
